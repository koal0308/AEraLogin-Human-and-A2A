# Contributing

This repository is a frozen reference implementation.

It is preserved for reproducibility, interoperability testing, security research and historical reference. New feature development should target the active AEraLogIn development repository instead.

## Issues

Use GitHub Issues for reproducible bugs in the frozen reference, documentation errors, and security-relevant observations that do not disclose sensitive details.

Do not publish credentials, private keys, production data or exploit details for an unresolved vulnerability.

## Pull requests

Pull requests should be narrowly scoped, reproducible, tested, documented and compatible with the frozen reference scope.

Feature work intended for the future AEraLogIn architecture should not be introduced here.

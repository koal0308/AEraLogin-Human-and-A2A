🤖 AEra Agents

Manage the autonomous Agents that act under your wallet. Each Agent has its own cryptographic identity and can authenticate and communicate through AEra.

🔒 Your Agent Runtime owns the keys. It generates the Ed25519 keypair and keeps the private key locally. This dashboard only ever sends the public key to AEra — never upload or paste a private key here.

➕ Create Agent

Step 1: name your Agent. Step 2: run one command on the machine where the Agent lives — its runtime creates the key there. Step 3: compare the fingerprint and approve with your wallet. You never handle a key yourself.

Connect your wallet to load available capabilities…

Approving signs an owner challenge with your wallet. This proves ownership — no gas fees are charged.

  1. Install or start your AEra Agent Runtime.
  2. The runtime generates an Ed25519 keypair.
  3. The private key stays with the runtime and must never be uploaded.
  4. Copy the generated public key.
  5. Paste the public key into the field above.
  6. Sign the owner challenge with your wallet.

⚠️ AEra does not ship a packaged Agent Runtime yet. There is no download and no CLI installer. If you are building your own runtime, generate the keypair with the same primitive the Agent Identity Layer uses: 

python -c "
from cryptography.hazmat.primitives.asymmetric.ed25519 import Ed25519PrivateKey
from cryptography.hazmat.primitives import serialization
import base64, pathlib

sk = Ed25519PrivateKey.generate()
raw_priv = sk.private_bytes(
    encoding=serialization.Encoding.Raw,
    format=serialization.PrivateFormat.Raw,
    encryption_algorithm=serialization.NoEncryption())
raw_pub = sk.public_key().public_bytes(
    encoding=serialization.Encoding.Raw,
    format=serialization.PublicFormat.Raw)

# Private key -> stays on this machine. Keep it secret.
p = pathlib.Path('agent_private_key.bin')
p.write_bytes(raw_priv); p.chmod(0o600)

# Public key -> paste this into the AEra dashboard.
print('ed25519:' + base64.urlsafe_b64encode(raw_pub).decode().rstrip('='))
"

The command prints only the public key — the one line starting with ed25519:. It writes the private key to agent_private_key.bin next to you and never transmits it anywhere. A working reference implementation of a runtime that generates the keypair, registers and authenticates lives in aera-agent-security-lab/src/identity/aera_client.py; the protocol is documented in docs/AGENT_IDENTITY.md.

🧠 Agent identity ≠ LLM provider. Your Agent's AEra identity belongs to its runtime, not to any model vendor. The same Agent can later use Grok, Claude, DeepSeek or another supported model — its agent_id, key_id and keys stay exactly the same. AEra never stores a provider API key.
